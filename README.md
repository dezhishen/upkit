# upkit

> 帮你管理一批 Windows 软件：检查更新、下载、替换，一次做完。

upkit 提供全屏界面，列出全部受管软件。程序逐个检查是否有新版本，发现后自动下载、
校验、备份原文件并替换；替换失败则回滚至原版本。

软件来源于订阅的源，源提供的软件会自动出现在列表中。

## 能帮你做什么

| | |
| --- | --- |
| **批量检查更新** | 无需逐个启动软件查看版本 |
| **批量更新** | 支持全部更新或仅更新选中项 |
| **安装与卸载** | 支持安装新软件；卸载时可保留用户数据 |
| **自动备份与回滚** | 替换前自动备份，失败自动恢复；事后可回滚至任一备份 |
| **结束占用进程** | 更新前自动结束占用安装目录的进程 |
| **保留用户数据** | 配置、用户数据、日志在更新与卸载时不会被删除 |
| **校验安装包完整性** | 下载完成后校验，不一致则不安装 |
| **冲突检测** | 同一软件的重复条目会被拦截并提示原因 |
| **敏感信息脱敏** | 密码、令牌等在日志中自动脱敏 |
| **便携迁移** | 整体复制目录即可继续使用，无需重新配置 |

## 安装

从 [Releases](https://github.com/dezhishen/upkit/releases) 下载 `upkit-windows-amd64.exe`
（ARM 设备选 `arm64`），放到任意目录 —— 比如 `%LOCALAPPDATA%\upkit`，双击运行即可。

程序为单文件分发，无需安装，无额外运行库依赖，仅支持 64 位 Windows。

## 首次使用

1. 双击 `upkit.exe`，启动全屏界面
2. 首次运行会在程序同级目录创建所需文件夹
3. 在「来源」面板添加源：
   - 按 <kbd>o</kbd> 添加官方源
   - 或按 <kbd>a</kbd> 填入源地址
4. 插件安装完成后，其管理的软件即出现在「概览」列表中
5. 按 <kbd>C</kbd> 检查更新，按 <kbd>U</kbd> 更新

## 软件来源

upkit 不内置软件，软件全部由**源**提供：

```
源（订阅条目）  →  插件  →  软件
```

- **源**：填入地址后，upkit 将其中的插件下载至 `plugin/` 目录。官方源按 <kbd>o</kbd>
  一键添加，也可按 <kbd>a</kbd> 填入自有地址
- **插件**：独立可执行程序，由源维护者提供，描述一组软件的下载地址、安装方式与版本判定规则
- **软件**：插件管理的软件显示在概览列表中，支持检查、更新、安装、卸载

插件默认**未启用**：安装后日志中会显示其校验值，填入后才会启用。
插件由第三方提供并可读写本机文件，请在确认来源可信后启用。

多个源提供的软件合并显示；重复条目以本地已有为准。

## 界面

```
upkit v1.2.3   已安装 3 · 可更新 2 · 待安装 0
 1 概览   2 详情   3 任务   4 日志   5 设置   6 来源
┌─ 概览 ───────────────────────────────────────────────┐
│ ▌ Ungoogled Chromium  可更新  152.0.1  →  153.0.8    │
│   VS Code             最新    1.99.0      1.99.0     │
└──────────────────────────────────────────────────────┘
按 ? 查看快捷键，c 检查更新                      ? 帮助  q 退出
```

六个面板：概览（软件列表）、详情、任务、日志、设置、来源（订阅与插件）。

按 <kbd>?</kbd> 可以随时查看快捷键。常用的是这几个：

| 按键 | 作用 |
| --- | --- |
| <kbd>1</kbd>..<kbd>6</kbd> / <kbd>Tab</kbd> | 切换面板 |
| <kbd>c</kbd> / <kbd>C</kbd> | 检查选中的软件 / 检查全部 |
| <kbd>u</kbd> / <kbd>U</kbd> | 更新（或安装）选中的 / 全部可更新的 |
| <kbd>p</kbd> | 预览执行计划（不实际改动文件） |
| <kbd>空格</kbd> | 临时启用 / 停用某个软件 |
| <kbd>x</kbd> / <kbd>r</kbd> | 卸载（保留数据）/ 回滚到上一次备份 |
| <kbd>E</kbd> / <kbd>I</kbd> | 导出清单 / 导入清单 |
| <kbd>s</kbd> | 保存设置 |
| <kbd>q</kbd> | 退出 |

在「来源」面板里：

| 按键 | 作用 |
| --- | --- |
| <kbd>o</kbd> / <kbd>a</kbd> | 添加官方源 / 添加订阅 |
| <kbd>d</kbd> | 删除选中的订阅 |
| <kbd>空格</kbd> | 启用 / 停用 |
| <kbd>r</kbd> | 重新拉取订阅 |
| <kbd>Enter</kbd> | 订阅：查看里面有哪些插件；插件：编辑它自己的配置 |

设置项（代理、下载限速、备份份数、日志等）均在「设置」面板中修改，按 <kbd>s</kbd> 保存。

## 数据存放位置

默认采用便携模式，全部文件位于 upkit 同级目录，整体复制即可迁移：

```
config/    设置、订阅信息
log/       运行日志
plugin/    插件
data/      各插件自己的数据
cache/     下载的安装包（下次更新可以复用，不用重新下）
backup/    更新前的备份（可以回滚）
temp/      更新过程中的临时文件（自动清理）
```

若 upkit 置于无写入权限的目录（如 `Program Files`），上述目录会自动迁移至
`%APPDATA%\upkit`。

日志中的密码与令牌会自动脱敏。

## 限制

- 仅支持 64 位 Windows
- 不支持后台服务，需保持窗口运行
- 不支持多实例运行
- 支持 zip 等常见压缩格式
- 插件未做数字签名，需自行确认来源可信
